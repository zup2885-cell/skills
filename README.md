## 从哪里开始

- 做选题和内容规划：先看 `content-strategy`。
- 处理本人抖音作品数据：先看 `tzfilm-douyin-tool`，再按阶段选择具体技能。
- 制作内容岗位简历：先看 `ip-form-resume-builder`。

## 使用方法

1. 打开所需目录的 `SKILL.md`，先确认适用范围、依赖与授权要求。
2. 按正在使用的 AI 工具支持的技能加载方式使用；本仓库不是通用的一键安装程序。
3. 涉及登录、数据采集、发布、发送评论或第三方同步时，以当前任务授权和对应说明为准。

## 能力与许可

- 技能说明不等于已安装的浏览器插件、桌面应用或已配置接口。
- 部分个人适配保留本机路径，换电脑时需调整；存在文件不代表业务流程已验证可用。
- 第三方来源及各自许可证应随目录保留；没有明确许可证的内容，不默认获得再分发授权。
- 不要把密码、Cookie、密钥、真实账号数据或私人资料提交到公开仓库。
