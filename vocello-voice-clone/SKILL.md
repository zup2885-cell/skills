# Vocello 音色克隆

此 Skill 是本地操作适配说明，不是 Vocello 官方提供的 MCP 插件。软件来源为 [PowerBeef/Vocello](https://github.com/PowerBeef/Vocello)，本机安装路径 `/Applications/Vocello.app`。安装时验证的是官方 v2.4.0 DMG；上游 main 描述的 3.0 功能不可直接当作已安装版本能力。

## 操作方式

- 使用当前可用的 Computer Use 工具操作原生 Vocello。首次选择应用后阅读当前工具文档，每次动作后读取新界面，再使用元素索引。
- 开始录音或生成前显示实际 Vocello 窗口。不能把说明网页、预览或右侧链接称为实际编辑器；原生窗口无法直接嵌入 Codex 网页侧栏。
- 没有官方 MCP 连接可用时，继续使用已验证的界面路径；不要编造服务端口、接口或命令行参数。

## 模型和音色

- Settings → Model downloads → Voice Cloning 下载 Base 克隆模型。安装一套克隆模型即可；不要为了克隆任务下载全部模式。16GB Mac 可用 Quality（1.7B 8-bit，约2.81GB），更低内存可选 Speed。通过状态 Installed 确认下载完成。
- Settings 的 Voice cloning 开关是声音授权声明；解释给用户，按当前授权和工具确认规则处理。用户自己的录音可用于其明确要求的克隆任务，陌生录音不能推断授权。
- Voice Cloning 使用录音、导入参考音频或已保存音色。录音由用户实际说话完成；首次麦克风系统权限按当前确认规则处理。未经明确请求不要开启录音。
- 参考音频应尽量干净、单人讲话、没有配乐；转写可提高条件匹配质量，若填写转写必须与参考音频一致。时长限制以应用当前界面为准。
- 保存到 Saved Voices 后，后续复用这个音色。不要上传用户声音、转写、音色文件或历史到公开 GitHub；仓库只备份本 Skill。

## 生成与交付

- 使用用户提供的文案，选择中文或目标语言，选择已保存的目标音色，先生成一小段试听；新应用未下载模型、未保存用户音色时不可报告克隆已完成。
- 克隆模式 v2.4.0 跟随参考音频表现，不宣称具备该版本没有的情绪控制。相似度、自然度和读音需要实际试听确认。
- 使用应用导出已生成的音频，核对实际输出文件和时长；通过绝对路径在聊天中提供音频试听或文件链接。
- 新版文案超过约300个中文字符时应用可能自动分段；以实际界面和生成结果为准，不承诺精确时长。

## 状态说明

分别报告应用安装、模型就绪、参考音色保存、生成成功。Skill 文件存在只证明流程已安装；在用户录音前不能证明其音色克隆效果。
